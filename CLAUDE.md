# Jev proof check

Checks a whole waste trip's proof with TypeSafe's Jev model: loading photos, unloading photos and weigh bills, against the vehicle number and quantity typed in. The trip must run tare → loading → gross → unloading: tare first at least `min_gap_tare_first` before gross, every loading photo between tare and gross, every unloading photo after gross, give or take `clock_slack` (`check_proof.Limits`, 60/5 min, changeable per run); gross first is flagged. Times and net weight come from the final slip (both weights); first slips only count for the vehicle number, handwritten notes are ignored. One clear matching plate per kind of photo is enough. When the plant's location is given as input (`--plant`, the page, or `trip.json`; never hard-code it), unloading photos' GPS stamp positions are read to four decimals and must place one photo within `plant_radius` (500 m) of the plant (`plant_check`): degrees and two decimals as Choices, then the Lat/Long line is found with a Box question (`jev-preview`), cut out, and the four-decimal value picked from 100 candidates (`read_line`). Images reused from other trips (`ImageIndex`) and a vehicle on two trips at once (`overlap_checks`, in `run_trips.py`) are flagged. Nothing is rejected automatically: a failed check flags the trip ("Flagged: problem found"), an unsure one asks a person ("Flagged: please check"), and a person accepts or rejects. See README.md for what it does and how to run it.

## Working on this project

- Use the `typesafe-ai` skill (plugin `typesafe@typesafe-ai`) for any change that touches Jev questions, state, models or the API. Follow it: read the relevant live docs at https://docs.typesafe.ai (append `.md` to a page path) before changing an integration, rather than relying on memory.
- Python lives in `.venv/` (`typesafe-sdk` 0.7.5, Pillow). Run code with `.venv/bin/python`.
- Run the offline tests after any change: `.venv/bin/python -m unittest discover -s tests -v`. They use a fake Jev API and need no key.
- The API key lives in GNOME Keyring (`secret-tool`, attributes `service typesafe account api`), read by `check_proof.api_key()`. Never look it up, print it, or write it to a file, the environment or `ui.html`; pass it straight to `TypeSafeClient(api_key=...)` server-side.
- Questions are defined once in `check_proof.py` (`QUESTIONS` per slot: `photo` for loading and unloading photos, `bill`; `REPORT`); `app.py`, `run_trips.py`, `evaluate.py` and the tests reuse them. Regenerate `playground/*-questions.json` from `QUESTIONS` after changing them. Keep rules and calculations (rotation, pass/fail/review decisions, the weighing order, gaps, photo timing and distances) in code, not in questions. The place questions (`PLACE`) are only asked of unloading photos when a plant is given, and are left out of `question_version` otherwise so older saved answers stay valid; the plant itself is never sent to Jev. Don't ask for the third or fourth decimal as a digit: Jev misread them, even on the cut-out line; picking a whole candidate value works (19 Oct 2026 runs). The box and pick questions are built in code (`LINE`, `pick`), not in `QUESTIONS`, and count in `question_version` with `place`. Bills come in two layouts (a time with each weight, or only Time In/Time Out); both are asked about and `weighings` picks.
- Jev can't transcribe text: the typed vehicle number and quantity (`quantity_kg`) go in the state and Jev judges whether the plate or bill shows them. `net_weight` is only asked when a quantity is typed. Don't list `same` first in a number question (Jev leans towards the first option).
- Image input is experimental in Jev and needs the `TypeSafe-Danger-Zone-Images: true` header (`check_proof.HEADERS`).
- Confidence thresholds (`CONFIDENT`, `YES`, `NO`, and `ROTATE` for turning an image, in `check_proof.py`) are placeholders. Choose them from `run_trips.py` and `evaluate.py` reports on real images, per question group and by risk, as the TypeSafe confidence docs advise.
- `trips/` holds real trip folders (real records: phone numbers, driver names) and a hand-read `truth.jsonl`; it, `eval/` and `mockups/` are gitignored. Never commit or publish them. Saved Jev answers in `eval/answers-<model>.json` let `run_trips.py --cached` re-check a day for free after a rule change.
